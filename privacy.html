Privacy Policy

Effective Date: September 16, 2026 • Last Updated: September 16, 2026

Summary: CmdVault is an open-source command line cheat sheet and reference application. When you sign in with GitHub via Firebase, we only access your public profile (username, email, avatar) to authenticate you and personalize your developer experience. We never sell your data, we do not access your private repositories, and we do not store passwords.

1. Information We Collect When You Login via GitHub

When you choose to authenticate using Login with GitHub, our application receives basic account information authorized through GitHub OAuth and Firebase Authentication:

  • GitHub Profile Information: Your public GitHub username, display name, user ID, and avatar profile picture.
  • Email Address: Your primary public or verified email address associated with your GitHub account.
  • Authentication Tokens: Temporary OAuth access tokens and session identifiers managed securely by Firebase Authentication.

What We DO NOT Access: CmdVault requests only the standard read:user scope. We never request or access your private repositories, source code, SSH keys, GPG keys, personal access tokens, or billing information.

2. How We Use Your Information

The information collected during GitHub authentication is used exclusively for:

  • Creating and managing your active session on CmdVault.
  • Displaying your GitHub username and avatar in the navigation bar.
  • Enabling personalized developer features such as saving, bookmarking, and starring favorite terminal commands.
  • Preventing abuse, malicious activity, and rate limit violations.

3. Third-Party Service Providers

CmdVault relies on reputable third-party cloud infrastructure to operate:

  • GitHub (Microsoft): Provides user identity authentication via GitHub OAuth 2.0. Subject to the GitHub Privacy Statement.
  • Firebase Authentication (Google Cloud): Handles secure token verification, user session management, and encryption. Subject to the Firebase Privacy and Security Documentation.
  • Vercel Edge Platform: Hosts the static web application and serverless runtime. Subject to the Vercel Privacy Policy.

4. Data Storage, Security & Retention

CmdVault does not maintain a private server storing sensitive user passwords. All authentication credentials and encrypted session tokens are handled directly by Google Firebase's ISO 27001 and SOC 2 compliant infrastructure over HTTPS/TLS 1.3 encryption.

We retain your profile data only for as long as your session is active. You may log out at any time to invalidate your active session tokens.

5. Your Rights & Account Deletion

You have full control over your data:

  • Revoking Access: You can revoke CmdVault's authorization at any time directly through your GitHub account settings under Settings → Applications → Authorized OAuth Apps.
  • Data Erasure: To request complete deletion of any cached profile records, you can contact us at sonavaneparthgit@gmail.com.

6. Contact Us

If you have questions about this Privacy Policy or data security on CmdVault, please reach out:

Email: sonavaneparthgit@gmail.com or visit our Contact Us page, or open an issue on our official GitHub Repository.
